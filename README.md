# 煌覇 KOUHA 公式サイト — 公式エンブレム組み込み版

白を基調に、余白・罫線・整ったグリッド・英字ラベルを使用し、スポーツクラブらしい公式感を強めた静的サイトです。黒・黄色・オレンジはアクセントとして使用しています。

## 内容
- `index.html` TOP
- `about.html` ABOUT / チーム紹介
- `recruit.html` RECRUIT / メンバー募集
- `news.html` NEWS
- `results.html` RESULTS
- `assets/css/style.css` スタイル
- `assets/js/main.js` モバイルメニュー
- `assets/images/team-placeholder.svg` 仮画像

## 仮画像の差し替え
写真を用意したら、`assets/images/` に画像を追加し、HTML内の `assets/images/team-placeholder.svg` を新しい画像のファイル名に変更してください。トップのメイン画像と下部の画像は、別々の写真にするとより自然です。

1. Instagram公式アカウント（@kouha_volley）へのリンクは設定済みです。
